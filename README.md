# Caça2

Aplicació web progressiva per gestionar l'activitat cinegètica: jornades, observacions, equipament, seguretat i consulta de mapa.

## Estat

Primera versió inicial en desenvolupament. Les dades normatives i els límits cinegètics s'han de validar amb fonts oficials abans de prendre decisions sobre l'activitat de caça.

## Desenvolupament

Aplicació estàtica amb HTML, CSS i JavaScript, preparada per a GitHub Pages i ús instal·lable com a PWA.
